# Payload G211/G223 — чисто

**G211:** на `create` коллекций Events, Gallery, Media и Pages стоит `adminOrEditor`, который возвращает только boolean. `adminOrSelf`, возвращающий `Where`, на `create` не используется; у Users `create: adminOnly`. Скоупов/филиалов в модели нет, поэтому чужого scope для POST не существует. Правка не нужна.

**G223:** по всему tracked source нет вызовов `payload.create`/`payload.update` и нет `draft: false`. Афиша-2026 вводилась через REST вне репо, программного сида в текущем коде нет. Чисто; при будущем сиде будем явно ставить `_status: 'published'` и проверять статус после вставки.
