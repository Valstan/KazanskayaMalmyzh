# Бокс с тремя жильцами: запас по памяти двукратный, дефицит — процессорный

Закрываю `recommend`-письмо от 18.07 (probe #061 повторно, теперь с `sabantuy` + `kazanskaya`
+ `rmz`). Мерили 25.07.2026 с dev-машины.

## Покой

| | |
|---|---|
| RAM | 1536 МБ всего, **731 занято, 804 доступно**, swap 0 |
| RSS юнитов | sabantuy 284 МБ, kazanskaya 215 МБ, rmz 216 МБ |
| Прочее | postgres ~65 МБ суммарно, nginx 6 МБ, journald 18 МБ |
| MemoryMax | 1024 / 768 / 512 МБ (сумма 2304 МБ при 1536 физических — оверкоммит по лимитам, по факту не используется) |
| OOM / throttle | за 30 дней **ноль** записей `oom-kill` / `Killed process`; у `rmz` в journald ничего по памяти |
| Диск | 6.4G из 9.8G, свободно 2.9G (**70%** — единственная метрика, которая ближе всех к границе) |

## Под нагрузкой

Три жильца грузились **одновременно**, по 30 параллельных соединений на каждого
(9000 запросов: 1500 на sabantuy `/`, 6000 на kazanskaya `/ /program /years /map`,
1500 на rmz `/`), 107 с.

- **Все 9000 ответов — 200**, ни одного таймаута (`--max-time 30`).
- **MemAvailable ниже 717 МБ не опускался** (минимум в первые секунды, дальше 740–785).
  Порог «< ~200 МБ → останавливать `rmz`» не приблизился и наполовину.
- RSS почти не сдвинулся: 282→288, 217→221, 218→223 МБ. Next-standalone под нагрузкой
  память не набирает.
- `load average` дошёл до **3.76 при `nproc = 1`** (Xeon E5-2680 v4). Пропускная
  способность в этом режиме — **~84 rps суммарно на три сайта**, дальше растёт очередь,
  а не потребление RAM.

## Вывод

`rmz` на день пика останавливать не нужно — по памяти запас двукратный. Бутылочное
горлышко бокса — **единственное ядро**: если когда-нибудь понадобится держать пик, спасёт
не выселение жильца, а кэш на nginx (`proxy_cache` для ISR-страниц) или больший тариф.
Уточнение к рецепту #061: мерить не только RAM, но и `nproc` + `load average` под
нагрузкой — на односокетных VPS первым упирается CPU.

Отдельная граблина к копилке: **SSH на бокс с dev-машины сейчас не поднимается напрямую**
(TCP-хендшейк проходит, дальше `Connection timed out during banner exchange` — почерк DPI,
родня G147). Рабочий обход — прыжок через Бокс 1:
`ssh -o "ProxyCommand=ssh -i ~/.ssh/id_ed25519 -W %h:%p valstan@831d0ce99bdf.vps.myjino.ru" -i ~/.ssh/id_ed25519_sabantuy -p 49338 valstan@…`
